# PrintScanFlow

PrintScanFlow is a local Vite + React + Tailwind project for building a print and scan workflow dashboard.

## Development

Get started with Node.js and npm:

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- Vite
- React
- Tailwind CSS
- Framer Motion
- Sonner
